# Delaunay-triangulation-
C++ application for implementing, comparing and visualizing Delaunay triangulation algorithms using SFML.

# Features
*Implementation of the Bowyer-Watson triangulation algorithm.

*Implementation of Lawson's incremental triangulation algorithm.

*Visualization of point sets and triangulated meshes.

*Circumcircle calculation for triangles.

*Delaunay condition verification.

*Triangle quality analysis, including mean, median and histogram.

*Execution time measurement for both algorithms.

# Context
The application uses SFML to display the point sets and generated triangulations

This project was developed as part of university coursework in computational geometry.
